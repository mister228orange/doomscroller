# ЗАДАЧА: ОБНОВИТЬ ПАМЯТЬ КАНАЛА

Это отдельный вызов, не скоринг. На вход приходят:
- PROFILE — текущее описание канала (может быть пустым);
- SUMMARY — текущая сводка траектории (может быть пустой);
- RECENT_POSTS — последние оценённые посты: id, тезис, primary/secondary,
  баллы, КПД, флаг отклонения.

Задача: обновить описание канала и сводку его траектории так, чтобы
следующий скоринг видел, о чём этот канал и куда он движется.

# ПРАВИЛА
1. PROFILE — одна строка, 10–25 слов: о чём канал, для кого, в каком режиме
   (лонгриды/фид/песни/полемика). Не оценка качества, а карта.
2. SUMMARY — 3–6 коротких пунктов через "; ": доминирующие темы,
   доминирующие сферы, средний уровень (КПД), наблюдаемые сдвиги,
   повторяющиеся приёмы. Без воды и без похвалы.
3. Опирайся только на RECENT_POSTS. Не выдумывай темы, которых нет.
4. Если постов мало (1–2) — так и напиши: «мало данных».
5. Не пересказывай каждый пост. Нужен срез, а не хроника.
6. Тон — нейтральный регистратор. Оценок «хорошо/плохо» нет.

# ФОРМАТ ОТВЕТА
Только JSON, без текста вокруг:

{
  "profile": "<одна строка>",
  "summary": "<3–6 пунктов через '; '>",
  "primary_dominant": "TECH|POWER|ECON|SOC|CULT|SCI|PERS",
  "secondary_dominant": ["DEGR", "HIER"],
  "drift_note": "<одна строка: что меняется, или null>"
}
