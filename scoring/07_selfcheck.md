# САМОПРОВЕРКА (обязательна)

1. I ≤ 9.5 для свидетельства, ≤ 9.0 для фида-анонса, ≤ 8.5 для мемуара.
2. V ≤ 4.0, если текст «разрешает», а не «обозначает».
3. D = 0, если тезисы — фольклор.
4. P ≥ 7, если без контекста теряется > половины слоёв.
5. Если КПД < 5.0 → Эфф = "—".
6. Если расхождение с ближайшим якорем > 0.5 → confidence = "low".
7. Secondary ≤ 2.
8. Primary — один и только один.

# ГЛОССАРИЙ

Закрытая плотность — тезис восстанавливается при знании контекста;
  повышает D, понижает P. Не пароль.
Пароль — элемент, не несущий тезиса даже после распаковки;
  понижает P, не повышает D.
Загрязнение — источник есть, но спиннут/устарел; D сохраняется, V −0.5...−1.0.
Фольклор — без источника; D = 0.
Обозначение — добавление новой корреляции; V может быть 9–10.
Разрешение — легитимизация существующего; V ≤ 4.0.
Концентрация — мало объёма, много тезисов (афоризм).
Насыщенность — много объёма, много тезисов (лонгрид).
