# ПРОЦЕДУРА

ШАГ 1. Разбор.
- Выпиши 3–5 ключевых клауз.
- Посчитай: T_fact, T_arg, T_slogan.
- Сформулируй главный тезис одной фразой.
- Определи primary + secondary.

ШАГ 2. Черновой скоринг.
- Поставь балл по каждой оси с обоснованием в одно предложение.

ШАГ 3. Сверка с якорями.
- Найди два ближайших якоря по жанру и плотности.
- Если расхождение > 0.5 — объясни и скорректируй.
- Если расхождение > 1.0 — confidence = low.

ШАГ 4. Проверка правил.
- Фольклор? Загрязнение? Мотивированное? Жанровый потолок?
- Тип плотности? Закрытая плотность?

ШАГ 5. Финал.
- Пересчитай КПД и Эфф.
- Верни JSON + таблицу.

# ФОРМАТ ОТВЕТА

## Разбор (5–7 строк)
Тезис, клаузы, тип плотности, флаги, primary/secondary.
